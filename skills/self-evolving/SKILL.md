# Self-Evolving Agent Harness

You are building a **Self-Evolving** agent harness — an agent that evaluates its
own performance after each run, reflects on failures, and applies improvements to
its own prompt, tools, and configuration between runs. The core loop is:

```
Run → Evaluate → Reflect → Apply → Repeat
```

Each generation, the harness executes the agent on a task, scores the transcript,
asks the LLM to propose improvements, applies approved changes, optionally runs
`pytest` as a safety gate, and then starts the next generation from a stronger
baseline. A `generations/` history log records every change so the evolution is
auditable and reversible.

## Accept a spec and scaffold a project

Given the user's spec (or ask for one if missing: domain, task type, evaluation
criteria), scaffold a complete Python project:

```
<project>/
├── pyproject.toml
├── .env.example
├── README.md
└── src/<package>/
    ├── __init__.py
    ├── config.py        # env/.env: model, base_url, api_key, max_steps
    ├── evaluator.py     # scores a run transcript against criteria
    ├── reflector.py     # LLM-powered reflection → improvement proposals
    ├── applier.py       # applies approved improvements to code/config
    ├── evolve.py        # main loop: run → eval → reflect → apply × N gens
    ├── prompt.py        # SYSTEM_PROMPT constant (editable by applier)
    ├── tools/           # tool modules, regenerated by the harness
    │   ├── __init__.py  # registry: @tool decorator, execute(), list_tools()
    │   └── examples.py  # 3-5 domain-relevant starter tools
    └── cli.py           # argparse: --task, --generations, --model
```

### 3. `tools/__init__.py` — tool registry

```python
import json
from typing import Any, Callable, get_type_hints

_REGISTRY: dict[str, Callable] = {}

def tool(fn: Callable) -> Callable:
    """Decorator: registers a function as an agent tool."""
    _REGISTRY[fn.__name__] = fn
    return fn

def list_tools() -> list[dict]:
    schemas = []
    hints = get_type_hints(dict, include_extras=True)  # fallback
    for name, fn in _REGISTRY.items():
        hints = getattr(fn, "__annotations__", {})
        params = {}
        for pname, ptype in hints.items():
            if pname == "return":
                continue
            params[pname] = {"type": ptype.__name__ if hasattr(ptype, "__name__") else str(ptype)}
        schemas.append({"name": name, "description": fn.__doc__ or "", "parameters": params})
    return schemas

def execute(name: str, args: dict) -> str:
    if name not in _REGISTRY:
        return json.dumps({"error": f"Unknown tool: {name}"})
    try:
        result = _REGISTRY[name](**args)
        return json.dumps(result, default=str)
    except Exception as e:
        return json.dumps({"error": str(e)})
```

import math, json
from datetime import datetime, timezone
from tools import tool

@tool
def calculate(expression: str) -> dict:
    """Evaluate a math expression safely."""
    allowed = {"__builtins__": {}, "math": math}
    result = eval(expression, allowed)
    return {"result": result}

@tool
def current_time() -> dict:
    """Return the current UTC time as ISO string."""
    return {"time": datetime.now(timezone.utc).isoformat()}

@tool
def word_count(text: str) -> dict:
    """Count words in the given text."""
    return {"count": len(text.split())}

### 5. `evaluator.py` — scores a run against criteria

```python
import json

def evaluate(transcript: list[dict], criteria: dict | None = None) -> dict:
    """
    Score a completed run. Returns {score: 0-100, breakdown: {...}, issues: [...]}.
    criteria: optional dict like {"completeness": 4, "correctness": 4, "efficiency": 2}
    Default weights: completeness 4, correctness 4, efficiency 2.
    """
    criteria = criteria or {"completeness": 4, "correctness": 4, "efficiency": 2}
    max_weight = sum(criteria.values())

    # Check if agent reached a final answer
    has_answer = any(
        "answer" in (json.loads(m["content"]) if isinstance(m["content"], str) else {})
        for m in transcript
        if m["role"] == "assistant"
    )
    # Count tool calls (proxy for efficiency)
    tool_calls = sum(
        1 for m in transcript
        if m["role"] == "assistant"
        and isinstance(m.get("content"), str)
        and '"action"' in m["content"]
    )
    # Check for errors in observations
    errors = sum(
        1 for m in transcript
        if m["role"] == "tool"
        and "error" in (m.get("content") or "").lower()
    )

    breakdown = {}
    breakdown["completeness"] = 10 if has_answer else 3
    breakdown["correctness"] = max(0, 10 - errors * 3)
    breakdown["efficiency"] = max(0, 10 - max(0, tool_calls - 3))

    weighted = sum(breakdown[k] * criteria.get(k, 1) for k in criteria)
    score = int(weighted / max_weight * 10)

    issues = []
    if not has_answer:
        issues.append("Agent never produced a final answer.")
    if errors:
        issues.append(f"{errors} tool error(s) encountered.")
    if tool_calls > 5:
        issues.append(f"Excessive tool calls ({tool_calls}); consider simplifying approach.")

    return {"score": score, "breakdown": breakdown, "issues": issues}
```

### 6. `reflector.py` — LLM-powered reflection and improvement proposals

```python
import json
from openai import OpenAI
from config import MODEL, BASE_URL, API_KEY

REFLECT_SYSTEM = """You are an improvement engine for an AI agent harness.
Given a run transcript and its evaluation score, propose SPECIFIC improvements.
Return a JSON object:
{
  "prompt_edits": ["instruction to add or change in the system prompt"],
  "new_tools": [{"name": "...", "code": "..."}],
  "tool_fixes": [{"tool_name": "...", "fix": "...", "code": "..."}],
  "config_tuning": {"max_steps": N},
  "reasoning": "why these changes should help"
}
Be concise. Each proposal must be a complete, runnable code snippet if it involves code.
Only include fields that have non-empty lists/values."""

def reflect(transcript: list[dict], evaluation: dict) -> dict:
    client = OpenAI(api_key=API_KEY, base_url=BASE_URL) if BASE_URL else OpenAI(api_key=API_KEY)

    user_msg = f"""## Run Transcript (last 10 messages)
{json.dumps(transcript[-10:], indent=2, default=str)}

## Evaluation
{json.dumps(evaluation, indent=2)}

Propose improvements to prevent the issues listed above and raise the score."""

    resp = client.chat.completions.create(
        model=MODEL,
        temperature=0.3,
        messages=[
            {"role": "system", "content": REFLECT_SYSTEM},
            {"role": "user", "content": user_msg},
        ],
        response_format={"type": "json_object"},
    )
    content = resp.choices[0].message.content or "{}"
    try:
        return json.loads(content)
    except json.JSONDecodeError:
        return {"prompt_edits": [], "new_tools": [], "tool_fixes": [], "reasoning": content}
```

### 7. `applier.py` — applies approved improvements

```python
import os, re, textwrap
from pathlib import Path

def apply_improvements(proposals: dict, project_root: Path, dry_run: bool = False) -> list[str]:
    """
    Apply the reflector's proposals. Returns a list of change descriptions.
    If dry_run=True, returns what *would* change without writing.
    """
    changes = []
    prompt_path = project_root / "src" / "prompt.py"
    tools_path = project_root / "src" / "tools" / "examples.py"

    # --- Prompt edits ---
    for edit in proposals.get("prompt_edits", []):
        changes.append(f"PROMPT EDIT: {edit}")
        if not dry_run and prompt_path.exists():
            content = prompt_path.read_text()
            # Append new instruction before the closing triple-quote
            content = content.rstrip().rstrip('"').rstrip("'")
            if content.endswith('"""'):
                content = content[:-3]
            content += f"\n{edit}\n\"\"\"\n"
            prompt_path.write_text(content)

    # --- New tools ---
    for tool_proposal in proposals.get("new_tools", []):
        name = tool_proposal["name"]
        code = tool_proposal["code"]
        changes.append(f"NEW TOOL: {name}")
        if not dry_run and tools_path.exists():
            content = tools_path.read_text()
            # Append the new tool function at the end
            if not code.strip().startswith("@tool"):
                code = f"@tool\n{textwrap.dedent(code)}"
            content = content.rstrip() + "\n\n\n" + code + "\n"
            tools_path.write_text(content)

    # --- Tool fixes ---
    for fix in proposals.get("tool_fixes", []):
        changes.append(f"TOOL FIX: {fix['tool_name']} — {fix['fix']}")
        if not dry_run and tools_path.exists():
            content = tools_path.read_text()
            if "code" in fix and fix["code"]:
                # Replace the entire function by name
                pattern = rf"(@tool\s*\ndef {fix['tool_name']}\(.*?\n(?:    .*\n)*)"
                if re.search(pattern, content):
                    content = re.sub(pattern, fix["code"] + "\n\n", content, flags=re.DOTALL)
                    tools_path.write_text(content)

    # --- Config tuning ---
    config = proposals.get("config_tuning", {})
    if config:
        changes.append(f"CONFIG TUNING: {config}")
        if not dry_run:
            env_path = project_root / ".env"
            lines = []
            if env_path.exists():
                lines = env_path.read_text().splitlines()
            for key, val in config.items():
                env_key = f"AGENT_{key.upper()}"
                found = False
                for i, line in enumerate(lines):
                    if line.startswith(f"{env_key}="):
                        lines[i] = f"{env_key}={val}"
                        found = True
                        break
                if not found:
                    lines.append(f"{env_key}={val}")
            env_path.write_text("\n".join(lines) + "\n")

    return changes
```

### 8. `evolve.py` — the main evolution loop

```python
import json, subprocess, sys
from datetime import datetime, timezone
from pathlib import Path
from openai import OpenAI
from config import MODEL, BASE_URL, API_KEY, MAX_STEPS, GENERATIONS
from prompt import SYSTEM_PROMPT
from tools import execute, list_tools
from evaluator import evaluate
from reflector import reflect
from applier import apply_improvements

PROJECT_ROOT = Path(__file__).resolve().parent.parent

def run_agent(task: str, max_steps: int = MAX_STEPS) -> list[dict]:
    """Execute the agent on a task. Returns the full message transcript."""
    client = OpenAI(api_key=API_KEY, base_url=BASE_URL) if BASE_URL else OpenAI(api_key=API_KEY)
    tools_schema = list_tools()
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": task},
    ]

    for step in range(max_steps):
        resp = client.chat.completions.create(
            model=MODEL,
            temperature=0,
            messages=messages,
            tools=[{
                "type": "function",
                "function": {
                    "name": t["name"],
                    "description": t["description"],
                    "parameters": t["parameters"],
                },
            } for t in tools_schema] or None,
        )
        msg = resp.choices[0].message
        if msg.tool_calls:
            for tc in msg.tool_calls:
                fn = json.loads(tc.function.arguments)
                observation = execute(tc.function.name, fn)
                messages.append({"role": "assistant", "content": None, "tool_calls": [tc]})
                messages.append({"role": "tool", "tool_call_id": tc.id, "content": observation})
        else:
            messages.append({"role": "assistant", "content": msg.content or ""})
            # Check if the agent produced a final answer
            try:
                parsed = json.loads(msg.content or "{}")
                if "answer" in parsed:
                    break
            except json.JSONDecodeError:
                pass
    return messages

def run_tests() -> bool:
    """Run pytest if present; return True if tests pass or are absent."""
    test_dirs = [PROJECT_ROOT / "tests", PROJECT_ROOT / "test"]
    for d in test_dirs:
        if d.exists() and any(d.glob("test_*.py")):
            result = subprocess.run(
                [sys.executable, "-m", "pytest", str(d), "-q"],
                capture_output=True, text=True, cwd=PROJECT_ROOT,
            )
            if result.returncode != 0:
                print(f"  ⚠ Tests failed:\n{result.stdout}\n{result.stderr}")
                return False
    return True

def evolve(task: str, generations: int = GENERATIONS) -> None:
    log_dir = PROJECT_ROOT / "generations"
    log_dir.mkdir(exist_ok=True)

    for gen in range(1, generations + 1):
        print(f"\n{'='*60}\n  Generation {gen}/{generations}\n{'='*60}")

        # --- Run ---
        print("Running agent...")
        transcript = run_agent(task)
        (log_dir / f"gen_{gen:03d}_transcript.json").write_text(
            json.dumps(transcript, indent=2, default=str)
        )

        # --- Evaluate ---
        evaluation = evaluate(transcript)
        print(f"  Score: {evaluation['score']}/100 | Issues: {len(evaluation['issues'])}")
        (log_dir / f"gen_{gen:03d}_eval.json").write_text(
            json.dumps(evaluation, indent=2)
        )

        if gen == generations:
            print("\nFinal generation reached. Done.")
            break

        # --- Reflect ---
        print("Reflecting...")
        proposals = reflect(transcript, evaluation)
        print(f"  Proposals: {len(proposals.get('prompt_edits', []))} prompt edits, "
              f"{len(proposals.get('new_tools', []))} new tools, "
              f"{len(proposals.get('tool_fixes', []))} tool fixes")
        (log_dir / f"gen_{gen:03d}_proposals.json").write_text(
            json.dumps(proposals, indent=2)
        )

        # --- Apply ---
        print("Applying improvements...")
        changes = apply_improvements(proposals, PROJECT_ROOT, dry_run=False)
        for c in changes:
            print(f"  ✓ {c}")
        (log_dir / f"gen_{gen:03d}_changes.json").write_text(
            json.dumps(changes, indent=2)
        )

        # --- Safety gate ---
        print("Running safety gate (pytest)...")
        if not run_tests():
            print("  ✗ Tests failed after changes. Rolling back is recommended.")
            print("    Check generations/ log and revert with git.")
            break
        print("  ✓ Tests passed (or no tests found).")
```

### 9. `cli.py` — command-line entry point

```python
import argparse
from evolve import evolve
from config import GENERATIONS

def main():
    parser = argparse.ArgumentParser(description="Self-Evolving Agent Harness")
    parser.add_argument("task", help="The task/prompt to evolve against")
    parser.add_argument("--generations", "-g", type=int, default=GENERATIONS,

    args = parser.parse_args()
    evolve(args.task, args.generations)

if __name__ == "__main__":
    main()
```

## Conventions and safety

- **Append-only by default**: the applier appends prompt edits and new tools; it
  never deletes existing code. This keeps each generation auditable.
- **Git commit each generation**: before applying changes, the evolve loop should
  `git add -A && git commit -m "gen N"` if in a git repo. The harness above logs
  to `generations/` but you should add a git commit step in production use.
- **Test gate**: `pytest` runs after every apply. If tests fail, the loop halts
  and prints instructions to revert. Never skip this in production.
- **No secrets in code**: load keys from `.env`; ship `.env.example` with dummy
  values only.
- **Token budget**: the reflector truncates transcripts to the last 10 messages to
  control context length. Tune as needed.
